# Портфолио — что где лежит

Откройте **`index.html`** — это оглавление со ссылками на все сайты.

```
портфолио/
├── index.html                      — оглавление всех сайтов
├── 1-новые-многостраничные/         — новые сайты (октябрь 2026), по 5 страниц
│   ├── kofeinya-kobalt/            — кофейня «Кобальт»
│   └── restoran-olkha/             — ресторан «Ольха»
└── 2-старые-одностраничные/         — ранние сайты, каждый в одном файле
    ├── 1-cafe.html                 — пекарня «Мука»
    ├── 2-salon.html                — студия красоты «Лиль»
    └── 3-shop.html                 — керамика «Глина»
```

- **Новые** сайты — это папки. Внутри каждой есть свой `README.md`: как поменять телефон, цвета и цены и как выложить сайт на GitHub Pages.
- **Старые** сайты — одиночные HTML-файлы. Открываются двойным щелчком.
- Новый сайт кладите в `1-новые-многостраничные/` и добавьте строку в `index.html` (в нём есть комментарий, как это сделать).
